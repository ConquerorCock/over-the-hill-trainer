FAQ

Questions, answered

Is Over the Hill Trainer really free? +

Yes. The project is free and open source. You can download the prebuilt Windows release from the official page or build it yourself from the repository source.

Which Windows versions are supported? +

The trainer targets Windows 10 and Windows 11 (64-bit). The bundled loader is designed to run without extra runtime dependencies on modern Windows builds.

How do the aimbot and speed hack work? +

Both modules hook into the game's runtime and apply configurable values — aim smoothing and FOV for the aimbot, and a movement multiplier for the speed hack. Each feature can be toggled independently with hotkeys.

Can I use the auto-skip level injector on its own? +

Absolutely. Every module is independent. You can run only the auto-skip injector, only the wallhack ESP, or any combination you prefer from the overlay menu.
